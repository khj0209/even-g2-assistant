# G2 Assistant

Even Realities G2 안경에서 쓰는 AI 어시스턴트입니다. 안경을 길게 누르고 말하면 모드 화면 앞에 대화창이 떠서 Claude가 답합니다.

```
┌──────────────────────────────────────────────────────────┐
│ [러닝] 안경 82%  3°/11°  14:07  AI 90%                    │  ← 상태 줄 (모드 · 배터리 · 기온 · 시각 · AI)
│ YouTube Music · 밤양갱 - 비비  1:23/3:45                  │  ← 재생 중 (없으면 비어 있음)
│                   5'12"                                   │  ← 모드별 큰 숫자 (이미지)
│                현재 페이스 /km                            │
│   시간 12:03   거리 2.31km   평균 5'20"                   │  ← 모드별 상세
└──────────────────────────────────────────────────────────┘
        길게 누르면 ↓ 모드 화면 앞에 대화창이 뜹니다
┌──────────────────────────────────────────────────────────┐
│ [러닝] 안경 82%  3°/11°  14:07  AI 90%                    │
│ YouTube Music · 밤양갱 - 비비  1:23/3:45                  │
│ ╭──────────────────────────────────────────────────────╮ │
│ │ > 이 페이스면 10km 몇 분?                            │ │
│ │ 지금 페이스면 52분 정도에 완주할 수 있어요.          │ │
│ ╰──────────────────────────────────────────────────────╯ │
└──────────────────────────────────────────────────────────┘
```
대화창은 탭(마지막 쪽에서) 또는 두 번 탭으로 닫히고, 20초 동안 조작이 없으면 저절로 닫힙니다. 일상 모드의 기본 화면은 큰 시계입니다.

## 기능 (MVP)

| | |
| --- | --- |
| 상단 상태 줄 | 안경 배터리 · 오늘 최저/최고 기온(Open-Meteo) · 현재 시각 · AI 토큰 잔여(월 예산 대비 %) |
| 대화창 | 길게 누르면 모드 화면 앞에 테두리 있는 대화창이 떠서 질문·답변을 보여주고, 끝나면 닫힙니다 |
| 음성 대화 | 안경 터치패드를 **길게 누른 채 말하고 손을 떼면** 답합니다 (push-to-talk) |
| API 키 | G2 Context 앱에서 입력, Android 키 저장소로 암호화 보관. 안경 앱은 연결 코드로 받아 메모리에만 둠 |
| 세션 선택 | 휴대폰에서 대화 세션(로컬) 또는 Claude 에이전트 세션(Managed Agents)을 골라 이어서 대화 |
| 안경 화면 미러 | 휴대폰 화면 맨 위에 안경 화면을 그대로 보여주고, 같은 조작(누르고 말하기·다음 쪽·취소)도 가능 |

## 안경 조작

- **길게 누르기 → 떼기**: 말하기 → 답변
- **탭 / 위·아래 스크롤**: 답이 길 때 쪽 넘기기
- **두 번 탭**: 듣는 중이면 취소, 답하는 중이면 중단, 그 외에는 앱 종료

## 휴대폰 화면

1. **G2 Context 연결**: G2 Context 앱에 보이는 8자리 연결 코드를 넣습니다. Claude API 키, 음성 인식, 상황 모드는 모두 G2 Context 앱에서 관리합니다.
2. **음성 인식**: 별도 키 없이, 안경 마이크 소리를 G2 Context가 휴대폰 자체 음성 인식(안드로이드 13 이상)으로 글자로 바꿉니다.
   Even SDK는 G2 자체 음성 인식을 외부 앱에 열어주지 않아서(마이크 원음만 제공) 이 방식을 씁니다.
   처음에는 한국어 음성 인식 모델을 내려받느라 한 번 실패할 수 있습니다.
3. **세션**: "새 대화"로 대화를 나누고 목록에서 이전 대화를 골라 이어갈 수 있습니다. "Claude 에이전트 세션"은 같은 API 키 계정의 Managed Agents 세션 목록을 가져옵니다.
4. **모델 · 토큰**: 모델(기본 Claude Opus 5.5, Sonnet 5.5, Haiku 5.5)과 월 토큰 예산을 정합니다.

### "AI 잔여 토큰"에 대해

Anthropic API는 일반 API 키로 계정 잔액을 조회하는 기능을 제공하지 않습니다. 그래서 이 앱은 **이 휴대폰에서 쓴 토큰**(응답의 `usage`)을
달마다 세고, 휴대폰에서 정한 월 예산 대비 남은 비율을 `AI 90%` 처럼 보여줍니다. 예산을 0으로 두면 사용한 토큰 수(`AI 12K`)를 보여줍니다.
실제 결제 한도는 [Console](https://console.anthropic.com/settings/limits)에서 워크스페이스 월 한도로 거는 것을 권장합니다.

### "Claude Code 세션 선택"에 대해

claude.ai/code 의 Claude Code 세션은 API 키로 접근할 수 있는 공개 API가 없어 MVP에서는 다루지 않습니다. 대신 API 키로 접근할 수 있는
**Claude Managed Agents 세션**(Anthropic이 호스팅하는 에이전트 세션)을 목록에서 골라 안경으로 대화할 수 있게 했습니다.
에이전트가 도구 사용 승인을 기다리면 안경에 "(휴대폰에서 승인이 필요해요)"가 표시됩니다(승인 UI는 다음 단계).

## 상황 모드 (G2 Context 안드로이드 앱)

AI는 지금 상황에 맞춰 답하는 방식을 바꿉니다. 상황은 같은 휴대폰에 설치하는 **G2 Context** 앱(`android/`)이 알아내고,
안경 앱은 5초마다 `http://127.0.0.1:8765/mode` 에서 읽어 상단 상태 줄에 `[운전]` 처럼 보여줍니다.

| 모드 | 자동 전환 조건 | AI의 답변 |
| --- | --- | --- |
| 운전 | 차량 이동 감지 (다른 모든 모드보다 우선) | 안경이 **Drive HUD**로 바뀜 (아래) |
| 러닝 | 달리기 감지 | 숫자 위주로 아주 짧게 |
| 운동 | 자전거 감지, 또는 삼성 루틴(헬스장 등) | 세트·횟수·휴식 위주 |
| 개발 | 삼성 루틴(회사 와이파이 등) | 정확한 용어·명령어 |
| 회의 | 캘린더에 지금 '바쁨' 일정 | 핵심만 한 문장 |
| 일상 | 그 외 | 기본 |

- 우선순위: 운전 → 루틴/직접 지정 → 움직임(러닝·자전거) → 캘린더 회의 → 일상.
- **삼성 모드 및 루틴**: 루틴의 동작에서 앱 → "앱 열기 또는 앱 작업" → G2 Context → `G2 개발 모드` 같은 바로가기를 고르면
  장소·와이파이·시간 같은 조건으로 모드가 바뀝니다. 반대 조건의 루틴에는 `G2 자동 모드` 를 넣어 자동 감지로 되돌리세요.
  다른 자동화 앱에서는 `g2context://mode/dev` 같은 주소를 열면 됩니다.
- 모드를 직접 고르는 것은 G2 Context 앱에서만 합니다(안경 앱은 그대로 따라감).
- **가사**: 재생 중인 곡의 시간 맞춤 가사를 [LRCLIB](https://lrclib.net)(무료, 키 없음)에서 받아, 재생 위치에 맞는 줄을 재생 정보
  아래에 보여줍니다(곡 제목·가수·길이만 전송). 영상 자막은 안드로이드 재생 정보에 담겨 오지 않아 지원하지 않습니다.
- **재생 정보**: G2 Context에서 "재생 정보 접근 허용"(알림 접근)을 켜고, 앱에 보이는 8자리 **연결 코드**를 Even 앱의
  G2 Assistant → 설정 → G2 Context 연결에 넣으면 재생 중인 음악·영상이 상태 줄 아래에 나옵니다. 같은 휴대폰의 다른 앱도
  로컬 주소를 부를 수 있어서, 재생 정보는 코드가 맞는 요청에만 보냅니다.
- APK: GitHub Releases 의 **android-latest** 에서 `g2-context.apk` 를 내려받아 설치합니다(`android/` 가 바뀔 때마다 자동 빌드).
  재생 정보를 읽는 "알림 접근" 권한 때문에 Play 프로텍트가 "기기 보호를 위해 앱이 차단됨"으로 설치를 막으면,
  Play 스토어 → 프로필 → Play 프로텍트 → 설정에서 잠깐 끄고 설치한 뒤 다시 켜세요(업데이트 때마다 같음).
  설치 후 앱에서 권한 허용과 "배터리 최적화 제외"를 꼭 눌러 주세요. 삼성 기기는 백그라운드 앱을 적극적으로 재웁니다.

### 운전 모드 = Drive HUD

운전 모드에서는 안경 화면을 [even-g2-HUD](https://github.com/khj0209/even-g2-HUD)의 Drive HUD(`src/drive`, even-g2-status에 넣었던 것과 같은 모듈)가 맡습니다:
속도와 제한속도(과속 경고), 단속 카메라 알림, 목적지 검색과 회전 안내(OSRM, Tmap 키 등록 시 Tmap), 진행 방향 미니맵, 주행 기록, 지도 미리 받기,
야간 밝기, 졸음 감지(실험). 전체 경로 지도(왼쪽 위 오버뷰)는 뺐고, 그 자리에 **재생 중인 곡과 지금 가사**가 나옵니다.
HUD 가운데 줄은 길 안내 중에만 도로·남은 거리·도착 시각을 보여주고, 시계·방위 같은 상태 표시는 없앴습니다.

- 운전 중에는 AI 대화를 쓰지 않습니다(안경 입력은 HUD가 받음).
- 두 번 탭이나 안경 메뉴 "운전 모드 끝내기"로 나오면, G2 Context가 운전이 끝났다고 할 때까지 다시 들어가지 않습니다.
- 목적지 검색·집/회사 등록·주행 기록·운전 설정은 휴대폰 화면의 "운전" 카드에 있습니다.

### 그 밖의 기능

- **웹 검색**: 경기 결과·뉴스·가격처럼 최신 정보가 필요한 질문은 Claude가 웹 검색(한 답변에 최대 3번)으로 확인합니다. 검색만큼 비용이 더 듭니다.
- **다음 일정**: G2 Context가 12시간 안의 다음 일정(제목·시작 시각, 연결 코드 필요)을 보내면 일상 화면 아래 줄에 보이고, 10분 전에 대화창으로 알립니다.
- **주차 위치**: 운전 모드가 끝날 때 위치를 저장하고, "차 어디 있어?"라고 물으면 Claude를 거치지 않고 방향·거리·주차 시각을 답합니다.
- **러닝**: 1 km마다 구간·평균 페이스를 대화창으로 알리고, 설정의 목표 페이스(분:초)와 비교해 몇 초 빠른지·느린지 보여줍니다.
- **차량 블루투스**: 차 오디오·핸즈프리 블루투스에 연결되면 운전 모드가 됩니다. G2 Context에서 "차량 블루투스에 연결됐을 때만 운전으로 판단"을 켜면 버스·택시에서는 운전 모드가 켜지지 않습니다.
- **에이전트 알림**: 30초마다 Claude 에이전트(Managed Agents) 세션을 확인해, 작업이 끝나거나 승인을 기다리면 일상·개발 모드에서 대화창으로 알립니다.
- **삼성헬스**: 삼성헬스가 Health Connect로 공유하는 오늘 걸음 수·어젯밤 수면·최근 심박을 G2 Context가 읽어(안드로이드 14+, 연결 코드 필요)
  일상 화면 아래 줄과 러닝·운동 화면에 보여줍니다. 워치의 연속 심박은 몇 분씩 늦게 들어올 수 있습니다.
- **SmartThings**: 안경에서 "거실 불 꺼", "에어컨 24도로" 처럼 말하면 Claude가 SmartThings 기기·장면을 제어합니다(G2 Context에서 로그인, 연결 코드 필요).
  SmartThings 개인 토큰은 24시간마다 만료돼서, 한 번만 OAuth 앱을 등록해 자동 갱신 로그인을 씁니다:
  1. PC(또는 Termux)에서 `npx @smartthings/cli apps:create` → **OAuth-In App** 선택 → 이름 `G2 Context` →
     권한(scope)에서 `r:devices:*`, `x:devices:*`, `r:scenes:*`, `x:scenes:*`, `r:locations:*` 선택 →
     Redirect URI에 `https://localhost/g2context` 입력 → 출력되는 **OAuth Client Id / Client Secret** 복사
  2. G2 Context → SmartThings 카드에 Client ID·Secret을 넣고 **저장하고 로그인** → 삼성 계정 로그인 → "연결됨"
  3. 앱 안 로그인 화면이 막히면 **브라우저로 로그인** → 로그인 뒤 열리지 않는 `https://localhost/g2context?code=…` 주소를
     복사해 붙여넣고 **붙여넣은 주소로 연결**
  - Secret과 토큰은 Android 키 저장소로 암호화해 G2 Context에만 두고, 안경 앱은 기기 목록·명령만 G2 Context를 거쳐 보냅니다.
- **Claude Code**: G2 Context의 "Claude Code 열기"로 claude.ai/code를 앱 안에서 열어 세션을 보고 이어서 작업합니다
  (Claude 계정 로그인 유지). Claude Code는 외부 앱용 공개 API가 없어 웹 앱을 그대로 띄우는 방식이고,
  Google 로그인은 앱 안 화면에서 막히므로 이메일 로그인이나 "브라우저로 열기"를 쓰세요.
  Claude 앱이 보내는 Claude Code 알림(작업 완료·승인 필요)은 G2 Context가 알림 접근으로 받아, **일상·개발 모드**일 때 안경
  대화창으로 보여줍니다. 다른 모드에서는 기다렸다가 일상·개발로 돌아오면 보여주고, 10분이 지난 알림은 버립니다.
  **컴퓨터 터미널에서 돌린 Claude Code**도 알림을 받으려면: G2 Context의 "컴퓨터의 Claude Code 알림" 카드에서 **훅 설정 복사**를 눌러
  컴퓨터의 `~/.claude/settings.json` 에 넣으세요(이미 `"hooks"`가 있으면 그 안에 합침). 작업이 끝나면(Stop)·확인이 필요하면(Notification)
  `curl`이 이 폰 전용 ntfy.sh 주소로 `done: 프로젝트` / `input: 프로젝트` 같은 짧은 알림을 보내고(Windows Git Bash에서 한글이 깨지지 않게 영어로 보내고 G2 Context가 "작업 완료"/"확인 필요"로 바꿔 표시), G2 Context가 그 주소를 직접 구독해 안경으로 넘깁니다
  (ntfy 앱 설치 불필요). 주소를 아는 사람은 알림을 읽을 수 있으니 공유하지 마세요.
  회사망처럼 HTTPS를 검사하는 네트워크에서 curl이 `SSL certificate problem`으로 실패하면, Windows(Git Bash)에서는 `curl --ca-native`(Windows 인증서
  저장소 사용)를, Mac에서는 회사 인증서를 합친 `--cacert` 파일을 쓰거나, 덜 안전하지만 `http://` 로 바꿀 수 있습니다.
- **가사**: 따라 부르기 쉽게 다음 줄을 0.1초 먼저 띄우고, 줄이 바뀌는 순간에 맞춰 화면을 갱신합니다.

## 보안

- **키는 G2 Context에만**: Claude 키는 G2 Context 앱에서 입력하고, *추출 불가능한* Android 키 저장소 AES 키로 **AES-GCM 암호화**해
  보관합니다. 안경 앱은 연결 코드가 맞는 로컬 요청으로 키를 받아 **메모리에만** 두고 저장하지 않습니다.
- **연결 코드**: G2 Context의 로컬 서버는 같은 휴대폰의 다른 앱도 부를 수 있어서, 키·재생 정보·음성 인식은 8자리 연결 코드가 맞는
  요청에만 응답합니다(모드와 회의 종료 시각만 코드 없이 공개).
- **보낼 곳 제한**: Claude 키는 `api.anthropic.com` 으로만 전송됩니다. 빌드된 페이지에는
  `connect-src` CSP가 들어가 그 외 호스트로의 네트워크 요청을 막고, `app.json` 의 네트워크 화이트리스트도 같은 호스트만 허용합니다.
- **노출 최소화**: 저장 후 입력칸을 비우고, 화면에는 `sk-ant-…wxyz` 처럼 끝 네 자리만 보여주며, 키를 로그에 남기지 않습니다.
- 위치는 날씨 조회에만 쓰며 소수점 둘째 자리(약 1 km)로 반올림해 보냅니다.
- 서버가 없는 구조라 API는 휴대폰에서 직접 호출합니다(SDK의 `dangerouslyAllowBrowser`). 키가 사용자 본인의 휴대폰에서 입력되고
  본인 계정으로만 쓰이므로 의도된 사용입니다. 이 앱을 다른 사람이 키를 넣는 공개 웹페이지로 배포하지는 마세요.

## 개발

```bash
npm install
npm run dev     # http://localhost:5173 — 일반 브라우저에서도 안경 미러와 함께 동작(미리보기 모드)
npm run qr      # Even 앱으로 스캔해서 실제 안경에서 개발 버전 실행
npm run sim     # Even Hub 시뮬레이터
npm test        # 단위 테스트
npm run typecheck  # 타입 검사 (CI에서도 실행)
npm run pack    # g2-assistant.ehpk 생성
```

`build`/`pack` 은 타입 검사 없이 Vite로만 빌드합니다. TypeScript 7은 네이티브 컴파일러라 Android(Termux)용 실행 파일이 없어서,
휴대폰 Termux에서도 `npm run pack` 이 되도록 타입 검사는 `npm run typecheck`(그리고 CI)로 분리했습니다.

## 배포 (GitHub Actions)

- **CI** (`.github/workflows/ci.yml`): 모든 push/PR에서 버전·아이콘 검사, 타입 검사, 테스트, 빌드, `.ehpk` 패키징 후 아티팩트로 올립니다.
- **Release to Even Hub** (`.github/workflows/release.yml`): 작업 브랜치(`claude/g2-ai-assistant-skkzlq`)에서 `app.json` 이 바뀌면
  (= 버전을 올리면) 자동으로 패키징 → Even Hub 업로드 → 베타 지정까지 합니다. `v*` 태그 push나 Actions 탭 수동 실행도 됩니다.
  별도 `main` 브랜치 없이 이 브랜치에서 바로 작업하고 배포합니다.

```bash
npm version patch --no-git-tag-version   # package.json + app.json 버전을 함께 올림
git commit -am "v$(node scripts/version.mjs get)" && git push   # → 자동 배포
```

### 베타 테스터

Actions 탭 → **Even Hub beta testers** → Run workflow 에서 `add` / `rm` / `list` 와 이메일(쉼표로 구분)을 넣고 실행합니다.
Even Hub 로그인은 시크릿에만 두고 쓰기 때문에, 휴대폰이나 맥에서 CLI로 직접 추가하지 않는 편이 안전합니다(로그인 갱신 시 시크릿의 로그인이 폐기될 수 있음).
공개 저장소라서 로그의 이메일은 가려집니다.

### 처음 한 번만

1. 맥에서 Even Hub 로그인 후, 앱을 Even Hub에 처음 등록합니다.
   ```bash
   npx evenhub login
   npm run pack
   npx evenhub create g2-assistant.ehpk --name "G2 Assistant" --tagline "픽셀 아기곰 AI 어시스턴트"
   ```
   (휴대폰 Termux에서도 됩니다. `build`/`pack` 은 Termux에서 동작하도록 타입 검사를 분리해 두었습니다.)
2. 로그인 정보를 저장소 시크릿으로 등록합니다.
   ```bash
   pbcopy < ~/.config/evenhub/credentials.yaml               # 맥
   termux-clipboard-set < ~/.config/evenhub/credentials.yaml # Termux (Termux:API 필요), 또는 cat 으로 출력해 복사
   ```
   GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret 에서 이름을 `EVENHUB_CREDENTIALS` 로 하고 붙여넣습니다.
3. Even Hub는 로그인을 갱신할 때마다 이전 토큰을 폐기하므로, 워크플로가 갱신된 로그인을 시크릿에 다시 저장합니다. GitHub → Settings(개인)
   → Developer settings → Fine-grained tokens 에서 이 저장소만 대상으로 **Secrets: Read and write** 권한을 준 토큰을 만들어
   `EVENHUB_SECRET_WRITER` 시크릿으로 등록합니다.

- 워크플로가 로그인을 갱신하면 맥에 저장된 로그인은 폐기됩니다. 맥에서 직접 CLI를 쓰려면 다시 로그인하세요.
- 맥에서 다시 로그인하면 반대로 시크릿의 로그인이 폐기될 수 있으니, 그때는 `EVENHUB_CREDENTIALS` 도 새로 등록하세요.

## 구조

```
src/
  core/       표시 형식, 글자 줄바꿈·쪽 나누기, 토큰 사용량, PCM→WAV
  platform/   Even 앱 브리지, 저장소, 암호화 키 보관함
  services/   Claude(Messages API · Managed Agents 세션), 음성 인식, 날씨
  glasses/    화면 배치(기본/대화창), 렌더러(바뀐 것만 전송), 안경/휴대폰 미러 출력
  app.ts      전체 조율 (길게 누르기 → 음성 인식 → Claude → 대화창)
  main.ts     휴대폰 설정 화면
scripts/      버전·아이콘 검사, 릴리스 노트, 아이콘 생성
```

## 알려진 제약 · 확인 필요

- 실제 G2 하드웨어에서는 아직 검증하지 않았습니다. 브라우저 미리보기와 단위 테스트, `.ehpk` 패키징까지 확인했습니다.
- 안경 마이크 PCM은 16 kHz · 16-bit · mono로 가정합니다(SDK 문서에 형식이 명시되어 있지 않음). 인식 결과가 이상하면 이 값부터 확인하세요.
- 안경 글꼴 폭은 웹에서 측정할 수 없어 글자 종류별 추정치로 줄을 나눕니다. 실제 화면에서 줄이 넘치면 `src/core/textlayout.ts` 의 폭을 조정하세요.
- 음성 인식은 휴대폰의 기본 음성 인식기가 외부 오디오 입력(안드로이드 13 API)을 지원해야 합니다. 기기에 따라 지원하지 않으면
  G2 Context가 오류 메시지를 안경 대화창으로 보내줍니다.
