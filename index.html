G2 Context가 운전을 감지하면 안경이 속도·제한속도·단속 카메라·길 안내·미니맵 화면으로 바뀝니다. 두 번 탭하거나 안경 메뉴 "운전 모드 끝내기"로 나오면, 운전이 끝날 때까지 다시 들어가지 않습니다.

    회사 미등록

    검색 결과의 "집"·"회사"로 등록합니다. 운전 화면의 안경 메뉴 "집으로"·"회사로"·"안내 종료"로 휴대폰 없이 안내를 시작하거나 끝냅니다.

    주행 기록

      지도 저장

      지나간 곳의 지도는 이 휴대폰에 저장되고, 길 안내를 시작하면 경로 전체를 미리 받습니다.

      운전 설정

      보정: 차를 세우고 정면을 본 채 누른 뒤 4초 안에 고개를 두 번 끄덕이세요. 제한속도·단속 카메라는 OpenStreetMap 기준이라 실제와 다를 수 있으니 항상 도로 표지판을 우선하고, 주행 중에는 휴대폰을 조작하지 마세요.

      대화

          현재 대화 기록

            설정

            G2 Context 연결 확인 중…

            Claude API 키, 음성 인식, 상황 모드는 같은 휴대폰의 G2 Context 앱에서 관리합니다. 연결 코드를 한 번 넣으면 이 화면은 G2 Context에서 키를 받아 메모리에만 두고(저장하지 않음), 안경 마이크 소리를 G2 Context의 휴대폰 음성 인식으로 글자로 바꿉니다. 연결 코드가 있어야 같은 휴대폰의 다른 앱이 키와 재생 정보를 읽지 못합니다.

            러닝

            러닝 화면에 목표보다 몇 초 빠른지·느린지 보여주고, 1 km마다 구간 기록이 대화창으로 뜹니다.

            모델 · 토큰

            안경 상단의 "AI n%"는 이번 달 예산 중 남은 비율입니다. 0으로 두면 사용한 토큰 수를 보여줍니다.

            사용법
            • 안경 터치패드를 길게 누른 채 말하면 모드 화면 위에 대화창이 뜨고, 손을 떼면 AI가 대답합니다.
            • 대화창에서 탭: 다음 쪽, 마지막 쪽이면 닫기. 위·아래 스크롤로도 쪽을 넘깁니다. 20초 동안 조작이 없으면 저절로 닫힙니다.
            • 대화창이 닫혀 있을 때 탭: 마지막 대화 다시 열기 (운동 모드에서는 세트 완료).
            • 두 번 탭: 듣는 중이면 취소, 답하는 중이면 중단, 대화창이 열려 있으면 닫기, 그 외에는 앱 종료.
