      현재 대화 기록

        Claude API 키

        현재: 확인 중…

        키는 이 휴대폰에만 암호화되어 저장되고 api.anthropic.com 으로만 전송됩니다. 저장 후 입력칸은 비워지고 화면에는 앞뒤 일부만 보입니다. 가능하면 Console에서 이 키 전용 워크스페이스에 월 사용 한도를 걸어 두세요.

        음성 인식

        현재: 확인 중…

        Claude API는 음성을 직접 받지 않아서, 안경 마이크 소리는 OpenAI 음성 인식으로 글자로 바꾼 뒤 Claude에게 보냅니다. OpenAI 키가 없으면 휴대폰 자체 음성인식을 씁니다(휴대폰 마이크 사용, 기기에 따라 지원하지 않을 수 있음).

        모델 · 토큰

        안경 상단의 "AI n%"는 이번 달 예산 중 남은 비율입니다. 0으로 두면 사용한 토큰 수를 보여줍니다.

        사용법

        • 안경 터치패드를 길게 누른 채 말하고, 손을 떼면 몽이가 대답합니다.
        • 답이 길면 탭하거나 위·아래로 스크롤해서 쪽을 넘깁니다.
        • 두 번 탭: 듣는 중이면 취소, 답하는 중이면 중단, 그 외에는 앱 종료.
