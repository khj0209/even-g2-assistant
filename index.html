      현재 대화 기록

        설정

        Claude API 키 확인 중…

        키는 이 휴대폰에만 암호화되어 저장되고 api.anthropic.com 으로만 전송됩니다. 가능하면 Console에서 월 사용 한도를 걸어 두세요.

        G2 Context 연결 (상황 감지 · 재생 정보)

        같은 휴대폰의 G2 Context 앱이 운전·러닝·회의 같은 상황을 알려줍니다. 연결 코드를 넣으면 재생 중인 음악·영상 정보도 안경 상단에 보입니다 (코드가 있어야 다른 앱이 재생 정보를 읽지 못합니다).

        음성 인식 확인 중…

        Claude API는 음성을 직접 받지 않아서, 안경 마이크 소리는 OpenAI 음성 인식으로 글자로 바꾼 뒤 Claude에게 보냅니다.

        모델 · 토큰

        안경 상단의 "AI n%"는 이번 달 예산 중 남은 비율입니다. 0으로 두면 사용한 토큰 수를 보여줍니다.

        사용법
        • 안경 터치패드를 길게 누른 채 말하고, 손을 떼면 몽이가 대답합니다.
        • 답은 20초 동안 보였다가 모드 화면으로 돌아갑니다. 모드 화면에서 탭하면 마지막 답을 다시 봅니다 (운동 모드에서는 세트 완료).
        • 답이 길면 탭하거나 위·아래로 스크롤해서 쪽을 넘깁니다.
        • 두 번 탭: 듣는 중이면 취소, 답하는 중이면 중단, 그 외에는 앱 종료.
