# G2 Assistant

안경 속 작은 픽셀 아기곰 **몽이**와 음성으로 대화하는 Claude AI 어시스턴트입니다.

## 주요 기능

- **누르고 말하기**: 터치패드를 길게 누른 채 말하고 손을 떼면 몽이가 Claude의 답을 보여줍니다.
- **상태 줄**: 안경 배터리, 오늘 최저·최고 기온, 시각, 이번 달 AI 토큰 잔여량을 항상 보여줍니다.
- **표정 있는 아기곰**: 듣고, 생각하고, 말하는 동안 몽이의 표정과 움직임이 바뀝니다.
- **세션 이어가기**: 휴대폰에서 이전 대화나 Claude 에이전트 세션을 골라 계속 대화할 수 있습니다.
- **안경 화면 미러**: 휴대폰에서도 안경 화면을 그대로 볼 수 있습니다.

## 조작

길게 누르기: 말하기 · 탭/스크롤: 쪽 넘기기 · 두 번 탭: 취소/중단/종료

## 알아두세요

- 본인의 Claude API 키가 필요합니다. 키는 휴대폰에만 암호화되어 저장되고 Anthropic API로만 전송됩니다. API 사용 요금은 본인 계정에 청구됩니다.
- 안경 마이크로 말하려면 OpenAI API 키(음성 인식)가 필요합니다. 키가 없으면 휴대폰 음성인식을 사용합니다.
- 날씨는 Open-Meteo에서 대략적인 위치(약 1 km 단위)로 조회합니다.

## 필요한 권한

- **네트워크**: Claude API, 날씨(Open-Meteo), 음성 인식(OpenAI)
- **안경 마이크 / 휴대폰 마이크**: 질문을 듣기 위해 사용
- **위치**: 오늘 기온 조회
